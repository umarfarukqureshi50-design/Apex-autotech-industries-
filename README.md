# Apex AutoTech Industries

A professional, responsive manufacturer website concept built with React, Vite and React Three Fiber.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Images

Place properly licensed images in `public/images/` using these filenames:

- factory.jpg
- cnc.jpg
- engine.jpg
- transmission.jpg
- brake.jpg
- suspension.jpg
- components.jpg

The current component paths are ready for those files.

## Note

The contact form is a front-end demo. Connect it to a real email/form service before production.
